Staff

Map each device PIN to a person, put them in a group, and set their own Time In / Time Out. Late is judged against each person’s Time In (or the default Work start in Settings when left blank) — the same rule applies no matter which device they punch on.

Settings

Work start / end are the defaults used only for staff who have no personal Time In / Time Out set on the Staff tab. Set an individual schedule per person there for an accurate punch rule — grace applies both to a late arrival and an early leave.

Read-only guarantee. The on-site agent only ever reads from devices — it never clears, wipes, or sends commands to a machine. If a device’s memory fills up, clear it on-site from the device menu.
